Glossary

One line per term, with the chapter that develops it.

TermMeaningChapter
datumOne exact value in a format's finite set.Values
code pointThe integer naming a datum; what a value stores.Values
code unitThe storage word for code points: UInt8 at K ≤ 8, UInt16 above.Values
formatA finite datum set with an encoding: Binary{K,P,SGN,EXT}.Values
aliasThe concrete named subtype (Binary8p4se) code should use.Values
binadeThe span between consecutive powers of two; datum spacing doubles per binade.Values
ulpThe datum spacing at a given magnitude (unit in the last place).Values
projectionThe single rounding-plus-saturation step from exact result to code point.Computing
ProjSpecA named (rounding mode, saturation mode) pair, e.g. RNE_SN.Computing
SatNoneThe draft's full boundary rows — not "no saturation".Computing
stochastic modeRounding whose landing depends on a random draw R; a defined distribution.Computing
session defaultOne of five process-global settings behind + and friends.Computing
datum carrierThe exact type decode returns: Float64, Float128, or dyadic.Values
promotion carrierWhere Binary + ordinary number lands: Float64, or BigFloat for wide formats.Computing
defined resultThe draft-required code point for an operation, format, and spec.Assurance
tableA cached finite operation, entries produced by the scalar path.Data at Scale
block / scaleB elements sharing one scale; each lane is scale × element.Data at Scale
span filterThe integer test proving a Float128 accumulation is exact.Data at Scale
PackedVectorStorage at true bit width; compute unpacks internally.Data at Scale
κ (kappa)A registered approximation's measured worst-case error, in code points.Assurance
total orderThe draft's complete ordering; the single NaN sorts first.Values
exhaustiveChecked over every member of the input space, as opposed to sampled.Assurance
